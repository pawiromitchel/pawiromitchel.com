Most terminal price tickers I tried were one of two things: a stream of log lines that scrolls away before you've read the 24h change, or a Bloomberg-style dashboard that needs 160 columns before it stops wrapping.

What I actually wanted was the macOS Stocks widget: a card per asset, the change in green or red, and a small chart that shows at a glance whether it's been a good day. So I built that for the terminal as a weekend project in Go, with [Bubble Tea](https://github.com/charmbracelet/bubbletea) and Lipgloss: [CryptoWatcher](https://github.com/pawiromitchel/cryptowatcher).

## What it looks like

![CryptoWatcher showing crypto and stock cards with Braille line charts](/images/projects/cryptowatcher.png)

Each card shows:

- the symbol with a `▲` or `▼`, the full name and the market cap (`$1.57T`, `$297.3B`)
- the 24h change, colored
- a three-row line chart of the last 24 hours over a dotted baseline
- the current price

Crypto and stocks sit in separate sections, and a summary bar at the top shows how many assets you're watching, the biggest gainer and loser, and whether the feeds are connected. You move between cards with the arrow keys or `h`/`j`/`k`/`l`.

## Line charts out of Braille

The usual way to draw a sparkline in a terminal is with block characters: `▂▃▄▅▆▇█`. That works for bars, but a price line drawn that way looks like a staircase.

Braille characters are a better fit. Each one (`U+2800` to `U+28FF`) is a 2×4 grid of dots, and every dot is one bit:

```text
dot bits in one Braille cell:
  0x01  0x08
  0x02  0x10
  0x04  0x20
  0x40  0x80
```

So a single character cell gives you 2 columns and 4 rows of "pixels". Stack three rows of characters and you have 12 vertical steps per card instead of one, which is enough for a line that actually looks like a line.

The renderer maps each price in the 24h history onto that finer grid, draws straight segments between neighbouring points, and turns each cell's bits into a character:

```go
subWidth := width * 2       // 2 dots across per character
subHeight := chartRows * 4  // 4 dots down per character

for j, val := range history {
	x := int(math.Round((float64(j) / float64(numPts-1)) * float64(subWidth-1)))
	norm := (val - minVal) / diff
	y := (subHeight - 1) - int(math.Round(norm*float64(subHeight-1)))
	pts[j] = [2]int{x, y}
}

for j := 0; j < numPts-1; j++ {
	drawWidgetSubLine(subGrid, pts[j][0], pts[j][1], pts[j+1][0], pts[j+1][1])
}

// later, per cell:
rRune := rune(0x2800 + uint16(bitmask))
```

Connecting the points matters. If you only plot the points themselves, a sharp move leaves gaps in the chart.

## One watchlist, three price feeds

I wanted Bitcoin, a meme coin and Apple on the same screen, and no single free API covers all three. So price lookups go through a `MultiFetcher` that tries providers in order and uses the first one that returns a price:

```go
priceFetcher = fetcher.NewMultiFetcher(
	fetcher.NewCoinbaseFetcher(),   // majors: BTC, ETH, SOL, ...
	fetcher.NewCoinGeckoFetcher(),  // everything else on-chain
	fetcher.NewPythFetcher(),       // US stocks and ETFs
)
```

```go
func (m *MultiFetcher) FetchPair(ctx context.Context, rawInput string) (model.CryptoPair, error) {
	var lastErr error
	var lastPair model.CryptoPair

	for _, f := range m.fetchers {
		pair, err := f.FetchPair(ctx, rawInput)
		if err == nil && pair.Price > 0 && pair.Err == nil {
			return pair, nil
		}
		lastPair = pair
		lastErr = err
	}
	// ...
}
```

Coinbase's public API handles the big pairs and gives hourly candles for the chart without an API key. Anything Coinbase doesn't list (`PEPE`, `WIF`, `HMM`) falls through to CoinGecko, and tickers like `AAPL` or `SPY` end up at the stock feed. (The stock fetcher is named `Pyth`, but it reads Yahoo Finance's chart endpoint.) Every symbol on the watchlist is fetched in its own goroutine, so one slow provider doesn't hold up the whole screen.

Press `a`, type a ticker, and it gets resolved the same way and saved to `~/.config/cryptowatcher/config.json`.

## Keys

| Key | Action |
| :--- | :--- |
| `←` `↓` `↑` `→` or `h` `j` `k` `l` | Move between cards and sections |
| `a` / `+` | Add a ticker |
| `d` / `x` | Remove the selected card |
| `r` | Refresh now |
| `q` / `Ctrl+C` | Quit |

## Try it

On macOS or Linux:

```bash
brew install pawiromitchel/tap/cryptowatcher
cryptowatcher
```

There are also prebuilt binaries for macOS, Linux and Windows on the [releases page](https://github.com/pawiromitchel/cryptowatcher/releases/latest). A few flags are useful:

```bash
cryptowatcher -mock           # fake data, handy offline
cryptowatcher -interval 10    # refresh every 10 seconds instead of 5
cryptowatcher -config-path    # print where the watchlist is stored
```

The code is on [GitHub](https://github.com/pawiromitchel/cryptowatcher).
