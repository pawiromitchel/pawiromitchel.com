Building CryptoWatcher: Bringing macOS Stocks Widgets into the Terminal with Go

I wanted the glanceability of macOS Stocks widgets inside my tmux session. Here is how I built CryptoWatcher in Go using Bubble Tea, Lipgloss, high-definition Braille line charts, and composite multi-feed asset routing.

Most terminal market tickers fall into two camps:

  1. The Wall-of-Text Ticker: A scrolling stream of 1-line text logs that scrolls off your screen before you can read the 24h delta.
  2. The Cluttered Full-Screen Bloomberg Clone: Massive terminal dashboards that require 160 columns of terminal width just to render 4 assets without clipping text.

I love the visual design of the macOS Stocks widget: clean rounded cards, prominent delta badges, high-contrast typography, and a subtle sparkline that immediately tells you whether an asset is breaking out or dumping.

I decided to build that exact experience for the terminal as a weekend project in Go: CryptoWatcher.

Every card gives you:

  • Directional Momentum: Up/Down indicator (▲/▼) with symbol, company/token name, and formatted market cap ($1.57T, $297.3B, $49.6B).
  • High-Definition Braille Sparklines: A 3-row mini line chart with a reference dotted baseline (┄┄┄┄┄┄) that shows price trajectory over the last 24 hours.
  • Top Summary Status Bar: Active monitored count, current top 24h gainer, top loser, and multi-feed connectivity status.
  • 2D Grid Navigation: Move across cards and categories seamlessly using either arrow keys or standard Vim bindings (h/j/k/l).

Under the Hood: High-Resolution Braille Line Charts

Rendering clean curves in a text-based terminal usually relies on block characters like , ▂, ▃, ▄, ▅, ▆, ▇, █. While block characters work for bar charts, they look jagged for line trends.

In cryptowatcher, the sparkline renderer uses Unicode Braille patterns (U+2800 through U+28FF).

Why Braille?

A standard terminal character cell is roughly a 2:1 vertical rectangle. Unicode Braille matrices feature a $2 \times 4$ dot grid per character cell:

By stacking 3 Braille cells vertically, we achieve 12 distinct sub-pixel vertical steps per character column instead of just 1.

This sub-pixel precision produces continuous, smooth curves even inside a compact 26-character-wide card.

MultiFetcher: Smart Asset Routing Across Feeds

In a single dashboard, users want to monitor Bitcoin, micro-cap tokens, and the S&P 500 simultaneously. No single public API serves all three reliably without expensive subscriptions or restrictive rate limits.

To solve this, CryptoWatcher implements a composite MultiFetcher interface that dynamically classifies and routes ticker symbols:

  1. Coinbase Exchange API: Used for major crypto pairs (BTC-USD, ETH-USD, SOL-USD). Provides high-frequency orderbook snapshots and complete 24-hour hourly candle arrays without requiring an API key.
  2. Equity Feeds: Resolves US equities and index ETFs (SPY, TSLA, GOOGL, AAPL) with 24-hour high/low metrics and market cap formatting.
  3. CoinGecko Resolver: Used as a dynamic fallback for tokens not listed on Coinbase (e.g. PEPE, WIF, BONK, HMM).

When you press a in the dashboard and type a ticker name, the routing engine queries the fetcher pool concurrently, automatically infers whether it belongs in the Cryptocurrency section or the Stocks & Equities section, and persists the update to ~/.config/cryptowatcher/config.json.

Keyboard-First Productivity

Because it was built for developers who live in tmux and terminal splits, every interaction is keyboard-driven:

KeyAction
c / vToggle between Sparkline Chart and Big Price Hero view
h / j / k / l or ← / ↓ / ↑ / →2D navigation across cards and sections
a / +Open interactive modal to add any stock or crypto pair
d / xRemove selected widget card with safety confirmation prompt
rForce instant refresh across all active tickers
qQuit cleanly, restoring terminal alternate screen buffer
